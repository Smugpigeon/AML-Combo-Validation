{% if lang == 'zh' %}

5000 基因 panel 是什么:Kit 的 Layer-3 MLP 模型在 BeatAML 2.0 数据集上训练时用了 5000 个特征基因(从原始 ~22,000 个基因里通过特征工程筛选出来的最有预测力的子集)。这是 固定的训练时基因清单,所有新患者都按这套基因来对齐。

你需要怎么准备:

  • 2 列 CSV:symbol,count
  • 第一列是 HUGO 基因符号(如 FLT3、NPM1),大小写敏感
  • 第二列是 表达数值 —— raw counts、CPM、TPM 都行,kit 内部会做 quantile-normalize 对齐到 BeatAML 训练分布
  • 可以上传 多于 5000 行,kit 自动选 panel 内的子集
  • 少于 5000 也行,缺的基因插补为 0 + 报告里加 QC 警告

典型来源:STAR 比对 + featureCounts / Salmon / Kallisto 等任意 RNA-Seq 流程的输出,选你的那个样本一列,导出成 CSV。

临床实验室通常的格式:大部分医院 RNA-Seq 出的是基因 × 样本矩阵(如 Excel 一列叫 GENE,后面每列一个样本)。把你目标样本那一列提取出来配上 GENE 列,2 列存成 CSV 即可。

{% else %}

What it is: The Layer-3 MLP was trained on 5,000 specific gene-expression features selected from BeatAML 2.0 (originally ~22k genes — feature engineering picked the 5,000 with the most signal for ex-vivo drug-response prediction). This list is fixed at training time — all new patients align to it.

How to prepare your file:

  • 2-column CSV: symbol,count
  • Column 1 = HUGO gene symbol (e.g., FLT3, NPM1), case-sensitive
  • Column 2 = expression value — raw counts, CPM, or TPM are all fine; the kit quantile-normalizes to the BeatAML training distribution internally
  • More than 5000 genes is fine — kit picks its panel subset
  • Fewer than 5000 is fine too — missing genes imputed to 0 with a QC warning in the report

Typical source: output of any RNA-Seq pipeline (STAR + featureCounts, Salmon, Kallisto, etc.) — extract your target sample's column.

Hospital export format: most hospitals provide a gene × sample matrix (e.g., one column "GENE" + one column per patient). Pull your sample's column, save as 2-col CSV.
