API documentation

All endpoints are under https://amlcombo.org/api/v1/. Authenticate with Authorization: Bearer ac_live_....

Authentication

Generate an API key at /api-keys after signing in.

curl -H "Authorization: Bearer ac_live_xxxxxxxxxxxxxxxxxxxxxxxx" \
     https://amlcombo.org/api/v1/patients

Submit a patient

POST /api/v1/patients — multipart/form-data

Fields:

  • payload_json — JSON string (see schema below)
  • rna_counts — CSV file (symbol,count) for the 5000-gene panel
  • rna_full — optional CSV file (full transcriptome)

payload_json schema

{
  "patient_label": "AML-2024-017",
  "age": 45,
  "sex": "female",
  "is_initial_diagnosis": true,
  "karyotype_text": "46,XX[20]",
  "fusions": [],
  "mutations": [
    {"gene": "FLT3", "is_ITD": true, "allelic_ratio": 0.62, "vaf": 0.45},
    {"gene": "NPM1", "variant_type": "missense", "vaf": 0.42}
  ],
  "wbc": 95.0, "platelet": 32.0, "hemoglobin": 8.5, "ldh": 1240.0,
  "blast_pct_bm": 78, "blast_pct_pb": 65
}

Returns 202 Accepted with a submission ID. Poll GET /api/v1/patients/{id} until status == "done", then fetch reports from /api/v1/reports/{id}/{pdf,html,markdown,figure}.

Endpoints

MethodPathDescription
POST/api/v1/patientsSubmit a new patient
GET/api/v1/patientsList your patients
GET/api/v1/patients/{id}Get submission status + results
DELETE/api/v1/patients/{id}Delete submission + artifacts
GET/api/v1/reports/{id}/markdownReport as Markdown
GET/api/v1/reports/{id}/htmlReport as styled HTML
GET/api/v1/reports/{id}/pdfReport as PDF
GET/api/v1/reports/{id}/figureDNA-profile PNG
POST/api/v1/reports/{id}/llm-summaryGenerate plain-English summary via your stored LLM key
POST/GET/DELETE/api/v1/keysManage platform API keys
POST/GET/DELETE/api/v1/llm-keysManage BYOK LLM keys

Rate limits

Free tier: 10 patient submissions per 24 hours. Reports are kept indefinitely.
